# Sprint 1 — Cadrage et conception V1

## Contexte du projet

Transformer le dossier de conception accumulé depuis la Phase 0 en un **plan d'exécution gelé** :

- un périmètre V1 tenable en six jours de développement ;
- une composante agentique choisie et justifiée ;
- une stack arrêtée ;
- une architecture ;
- un contrat personnel de critères d'acceptance vérifiables.

Ce sprint consolide et tranche, il ne part pas d'une page blanche. Si le dossier arrive mûr, le formateur peut le valider dès la fin du premier jour. Le temps gagné part sur le sprint 2.

## Travail attendu

1. **Reformuler le besoin en une page** : à qui le projet sert, le parcours principal promis, ce que la V1 ne fera pas (hors-périmètre assumé).
2. **Dimensionner le périmètre V1** pour six jours de développement (adapter l'ambition du sujet).
3. **Choisir la composante agentique majeure** (menu du dispositif) et justifier pourquoi elle sert ce besoin.
4. **Arrêter la stack** : socle du parcours par défaut ; toute dérogation est argumentée (un élément exotique maximum).
5. **Produire les schémas** :
   - l'architecture complète (données → agent(s) + garde-fous → interface → API) ;
   - le schéma de pilotage (chaîne CI/CD, environnements, signaux) esquissé au brief préparatoire.
6. **Écrire le contrat personnel** : 4 à 6 critères d'acceptance fonctionnels, propres au projet, au format **Étant donné / quand / alors**.
7. **Planifier les sprints 2 à 5** : quoi, dans quel ordre, avec quels risques.

## Modalités d'évaluation

Évaluation par un pair.

- [ ] Le besoin est reformulé clairement : un tiers comprend à quoi sert le projet en une page.
- [ ] Le périmètre V1 est tenable en six jours par une personne : l'évaluateur se prononce, le formateur tranche.
- [ ] Le hors-périmètre est assumé et écrit, pas implicite.
- [ ] La composante agentique est à la hauteur du parcours et sa justification tient.
- [ ] La stack est justifiée ; toute dérogation est argumentée.
- [ ] Les critères du contrat personnel sont vérifiables (on peut dire oui ou non en les lisant).

## Livrables

Le **dossier de conception V1**, versionné dans le repo et validé par le formateur :

- besoin ;
- périmètre gelé ;
- composante justifiée ;
- stack ;
- schémas ;
- contrat personnel ;
- plan.

> C'est la porte d'entrée de la série : **aucune ligne de code avant.**
